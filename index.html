A little tip

Matching images and masks are paired automatically by filename.

Browsers cannot reveal local folders or access absolute paths.

Match folders

Drag paths into Base or Masks, or use the arrow buttons. Select a base path to edit its masks and rule. Paths include subfolders and can appear on both sides. Existing pairs are preserved.

The mask path will be selected in the folder picker.

Choose a known base and mask from the assigned paths. Search by filename, then select the shared ID. Search results show up to 100 files.

Match the filename without its extension. The first capture group must contain the shared ID.

      Showing up to 20 proposed pairs. Nothing changes until you apply.

      Remove folders

      Remove files directly in the selected folders from the viewer. Files in other folders are kept, including unpaired bases and masks. Nothing is deleted from disk.
